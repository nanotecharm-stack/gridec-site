# powertech.am

The site is being rebuilt. This repository currently serves one English
maintenance notice at index.html, hy.html and 404.html, plus the CNAME that
holds the custom domain.

The previous site is not lost: it is commit fa4deeb, one before the notice.
Recover it with `git checkout fa4deeb -- .`

The repository must keep existing while DNS for powertech.am points at GitHub
Pages. Deleting it would leave the domain unclaimed on GitHub, and an unclaimed
custom domain can be taken over by anyone who adds it to their own Pages site.
